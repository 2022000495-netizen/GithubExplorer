No projeto GithubExplorer, adicione a listagem de Pull Requests de um repositório na página de detalhes, de forma análoga à listagem de issues já existente. Crie uma seção (ou aba) que exiba os pull requests abertos, mostrando título, autor, data de criação e um link para o PR no GitHub, consumindo a API pública do GitHub. Mantenha o padrão visual, de navegação e de código já existente no projeto.
